# Metacognitive-Prompt-AI-Agent-for-Problem-Posing-Training
一个面向初中学生问题提出能力培养的元认知提示AI智能体

在核心素养体系中，学生能否主动提出问题、评价问题并以问题驱动学习，被视为学习者深度学习的关键指标之一。当前多项实证研究指出，问题提出能力（Problem-Posing Ability）是学生创造性思维、批判性思维与元认知能力的综合体现，却长期处于课堂教学中被忽视或难以系统培养的状态。多数学生依旧停留在被动接受知识，缺乏主动质疑、反思的意识，甚至不知如何发起一个“好问题”。

伴随大模型（LLM）的快速发展，AI已在学习分析、对话式支持、提示式学习（Prompt Learning）等方面展现出巨大潜力量。但如何让AI不只是提供答案，而是成为促进学生“提出问题”的认知支架，目前仍在萌芽阶段。本研究正切入这一前沿的交叉点。

近年来的研究同时也指出，“元认知提问提示”能够显著提升学生提问质量与学习表现。然而，这类提示往往需要即时、连续且个性化的反馈，且对教师在元认知的理解和应用能力等方面有着较高的要求,在实际教学中难以做到。在此背景下，AI大模型因具备即时分析内容、生成个性化支架、开展对话式互动的能力，可以被视为为学生提供元认知提示的理想载体。

基于此，开展“AI辅助的元认知提问提示对学生问题提出能力的影响研究”，不仅具有一定的学术价值，也具备重要的实践意义。本项目拟构建一个基于本土化语言模型的AI提问支持原型系统，为学生提供实时的元认知提问提示（如策略提示、角度提示、深度提示等），并通过实验探究该系统是否能有效促进学生在学习任务中提出更高质量的问题。

本项目组成员来自教育技术学专业以及智能科学与技术专业，在人工智能基础、教学设计、学习科学、教育研究法等方面具备相应的知识储备。

本项目关注的是：AI作为教学辅助工具，通过元认知取向的提问提示（Metacognitive Prompting），能否有效促进学生的问题提出能力？
    其核心逻辑包括：
    1. AI的即时提问提示可以作为近侧发展区支架，让学生意识到“应该如何思考”，而非直接给出答案。
    2. 元认知提示（如“你为什么这样想？”“还可能有哪些角度？”）已被证明能促进深层思考，但传统教师难以实时提供。
    3. AI系统可进行可持续、个性化、动态的提示，从而系统性提升学生提出问题的质量与数量。

本研究拟通过 AI 辅助的元认知提问提示设计与实验，系统验证其对学生“问题提出能力”的影响，并构建“本土化提示模型与评价框架”，为教育技术实践提供实证数据。
