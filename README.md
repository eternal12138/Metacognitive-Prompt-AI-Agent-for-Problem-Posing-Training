> **TL;DR**  
> 🧠 **AI 探究思维助手** 是一款面向初中学生的问题提出能力培养 AI 原型系统。系统基于大语言模型（LLM）与元认知提示（Metacognitive Prompting）理论，通过智能对话、认知支架和问题优化反馈，引导学生从“回答问题”转向“发现问题、提出问题、深化问题”。

---

## ✨ 项目简介

在核心素养体系下，学生能否主动发现问题、提出问题，并利用问题驱动学习，被认为是深度学习的重要表现之一。

但在传统课堂环境中，很多学生长期处于“接受知识”的学习模式，对于以下能力往往缺乏系统训练：

- ❓ 如何发现值得探究的问题
- 💡 如何提出有深度的问题
- 🔍 如何评价自己提出的问题质量
- 🧭 如何在提问过程中反思自己的思维路径

大量研究表明，**问题提出能力（Problem-Posing Ability）** 是创造性思维、批判性思维和元认知能力的重要体现。

本项目提出：

> 🚀 **基于元认知提示的 AI 问题提出训练智能体**

利用人工智能大模型的实时交互能力，为学生提供持续、个性化的思维支持，使 AI 从“答案提供者”转变为：

> 🌱 **学生思维发展的认知伙伴**

## 🎯 项目目标

本项目关注的核心问题是：

> **AI 辅助的元认知提问提示，能否有效促进初中学生的问题提出能力？**

围绕这一问题，项目目标包括：

- 📌 培养学生主动发现问题的能力
- 📌 提升学生提出高质量问题的能力
- 📌 增强学生反思自身思考过程的能力
- 📌 探索 AI 支持深度学习的新模式

---

## 🌟 项目亮点

### 1. 🤖 从“AI 答题”到“AI 促思”

传统 AI 更常见的模式是：

```text
学生提问
   ↓
AI 给出答案
```

而本项目强调：

```text
学生产生想法
      ↓
AI 元认知提示
      ↓
学生反思与修改
      ↓
形成高质量问题
```

✅ AI 不替学生思考，而是帮助学生**学会思考**。

### 2. 🧠 元认知提示驱动问题深化

系统通过多种提示促进学生思维发展：

| 提示类型 | 功能 |
| --- | --- |
| 💡 策略提示 | 帮助学生调整思考方式 |
| 🌍 角度提示 | 鼓励从不同视角观察问题 |
| 🔍 深度提示 | 引导进一步追问原因、影响与意义 |
| ✅ 评价提示 | 帮助判断问题是否具有探究价值 |

**示例：**

**学生：**
> 为什么植物需要阳光？

**AI：**
> 这是一个关于植物生长的问题。你是否还能进一步思考：不同光照条件会带来什么差异？为什么会出现这些差异？

## ⚙️ 核心功能

### 💬 1. 智能提问引导
学生输入自己的想法后，系统不会直接生成答案，而是通过启发式对话帮助学生逐步完善问题。

### 🧩 2. 个性化认知支架
系统根据学生当前状态动态生成：

- 思考方向提示
- 问题深化建议
- 多角度探索提示
- 反思性追问

### 📈 3. 问题质量提升支持
系统帮助学生完成如下过程：

```text
发现现象
   ↓
提出初始问题
   ↓
接受 AI 提示
   ↓
优化与修改问题
   ↓
形成探究性问题
```

## 🚀 Installation

### 1. 创建 Python 环境

```bash
python -m venv .venv
```

Windows：

```bash
.venv\Scripts\python -m pip install -r requirements.txt
```

Linux / macOS：

```bash
.venv/bin/python -m pip install -r requirements.txt
```

### 2. 配置环境变量

请通过环境变量配置以下内容：

- `FLASK_SECRET_KEY`
- `ARK_API_KEY`
- `EMBEDDING_API_KEY`

⚠️ **不要直接将密钥写入源码。**
