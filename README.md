> **TL;DR:**\
> 🧠 AI 探究思维助手是一款面向初中学生的问题提出能力培养 AI
> 原型系统。系统基于大语言模型（LLM）与元认知提示（Metacognitive
> Prompting）理论，通过智能对话、认知支架和问题优化反馈，引导学生从"回答问题"转向"发现问题、提出问题、深化问题"。

------------------------------------------------------------------------

# ✨ 项目简介

在核心素养体系下，学生能否主动发现问题、提出问题，并利用问题驱动学习，被认为是深度学习的重要表现。

然而，在传统课堂环境中，学生长期处于知识接受模式，对于：

-   ❓ 如何发现值得探究的问题；
-   💡 如何提出具有深度的问题；
-   🔍 如何评价自己的问题质量；

往往缺少系统性的训练。

大量研究表明，**问题提出能力（Problem-Posing Ability）**
是创造性思维、批判性思维和元认知能力的重要体现。

本项目提出：

> 🚀 **基于元认知提示的 AI 问题提出训练智能体**

利用人工智能大模型的实时交互能力，为学生提供持续、个性化的思维支持，使
AI 从"答案提供者"转变为：

> 🌱 学生思维发展的认知伙伴。

------------------------------------------------------------------------

# 🎯 项目目标

本项目关注：

> **AI 辅助的元认知提问提示，能否有效促进初中学生的问题提出能力？**

核心目标包括：

-   📌 培养学生主动发现问题的能力；
-   📌 提升学生提出高质量问题的能力；
-   📌 增强学生反思自身思考过程的能力；
-   📌 探索 AI 支持深度学习的新模式。

------------------------------------------------------------------------

# 🌟 项目亮点

## 1. 🤖 从 AI 答题到 AI 促思

传统 AI：

    学生提问
       ↓
    AI 给出答案

本项目：

    学生产生想法
           ↓
    AI 元认知提示
           ↓
    学生反思与修改
           ↓
    形成高质量问题

AI 不替学生思考，而帮助学生学会思考。

------------------------------------------------------------------------

## 2. 🧠 元认知提示驱动问题深化

系统通过多类型提示促进学生思维发展：

  提示类型      功能
  ------------- --------------------------
  💡 策略提示   帮助学生调整思考方式
  🌍 角度提示   鼓励从不同视角观察问题
  🔍 深度提示   引导进一步追问原因和影响
  ✅ 评价提示   帮助判断问题探究价值

例如：

学生：

> "为什么植物需要阳光？"

AI：

> "这是一个关于植物生长的问题，你是否可以进一步思考不同光照条件会产生什么影响？"

# ⚙️ 核心功能

## 💬 1. 智能提问引导

学生输入自己的想法后，系统不会直接生成答案，而通过启发式对话帮助学生完善问题。

------------------------------------------------------------------------

## 🧩 2. 个性化认知支架

系统根据学生当前状态动态生成：

-   思考方向；
-   问题深化建议；
-   多角度探索提示；
-   反思性问题。

------------------------------------------------------------------------

## 📈 3. 问题质量提升

帮助学生完成：

    发现现象
        ↓
    提出初始问题
        ↓
    接受AI提示
        ↓
    优化问题
        ↓
    形成探究问题

# 🚀 Installation

## 1. 创建 Python 环境

``` bash
python -m venv .venv
```

Windows:

``` bash
.venv\\Scripts\\python -m pip install -r requirements.txt
```

Linux/macOS:

``` bash
.venv/bin/python -m pip install -r requirements.txt
```

------------------------------------------------------------------------

## 2. 环境配置

请通过环境变量配置：

-   `FLASK_SECRET_KEY`
-   `ARK_API_KEY`
-   `EMBEDDING_API_KEY`

不要直接将密钥写入源码。

------------------------------------------------------------------------

# ▶️ 启动项目

开发环境：

``` powershell
$env:APP_ENV="development"
$env:ARK_API_KEY="your_key"
.venv\Scripts\python.exe app.py
```

生产环境建议：

``` bash
gunicorn -c gunicorn_conf.py app:app
```
